# CPRFlow

CPRFlow is a Flutter-based CPR instructor workflow app for managing classes, student skill checklists, chest-compression-fraction (CCF) evaluations, written test scores, and archived class records.

## Current focus

- Instructor-first class and roster workflow
- Adult and infant CPR skill evaluation
- Live CPR / Pause CCF tracking
- Local persistence of active and archived class data
- Mobile-friendly CPR instruction and assessment tools

Clinical instructional content should be maintained against current resuscitation guidelines before production releases.
